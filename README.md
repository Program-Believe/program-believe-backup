# Program Believe – Backup Website

A simple standby site hosted free on GitHub Pages. Use it only if the main Base44 site has a long outage.

**Live backup URL:** https://program-believe.github.io/program-believe-backup/

## Switching to the backup during an outage
1. In this repo: Settings → Pages → Custom domain → enter `www.program-believe.com` → Save.
2. At your domain registrar, change the `www` CNAME record to `program-believe.github.io`.
3. When Base44 is back, point the `www` record back to Base44 and clear the custom domain here.

Donations go straight to Stripe (https://donate.stripe.com/eVq8wQ5Yt67T5Yp5u6eME08), so they work even when Base44 is down.
